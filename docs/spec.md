# 퇴근 후 삐-처리 정의서

> 상태: 초안 (2026-11-13, 지금 코드 기준으로 작성) · 승인 후 확정
> "정할 것"(12장)이 정해지기 전까지 해당 항목은 지금 코드 동작을 그대로 적었다.

## 1. 개요
- 직장인용 앱인토스(토스 인앱) 미니앱.
- 출근·퇴근까지 남은 시간을 카운트다운으로 보여주고, 퇴근하면 세계 각국의 귀여운 순화 비속어(minced oath)를 하나 뽑아 도감에 모은다.
- 모은 단어로 "아 우리 [XX]님 [YY] 같네" 짤을 만들어 이미지로 저장·공유한다.

## 2. 기술 스택과 제약
| 항목 | 내용 |
|---|---|
| 화면 | React 19 + Tailwind CSS v3.4 (v4는 `oklch()` 색 때문에 html2canvas 캡처 실패) |
| 빌드 | Vite |
| 캡처 | html2canvas 1.4 |
| 백엔드 | 없음 |
| 데이터 | 단어 DB는 정적 JSON, 유저 데이터는 localStorage (`bleep:` 접두사) |
| 실행 환경 | 토스 앱 웹뷰, 모바일 세로 화면, 기준 폭 375px |

## 3. 화면 구성
1. **홈**
   - 헤더: 제목, 근무 시간과 ⚙️ 버튼(설정 시트 열기)
   - 카운트다운 카드
   - "짤 만들기" 버튼 (모은 단어가 없으면 비활성)
   - 도감
2. **설정 시트** (아래에서 올라옴): 출근·퇴근 시각 입력, 저장. 바깥을 누르면 닫힌다.
3. **보상 모달**: 국가, 단어, 원어, 뜻, NEW 표시, [닫기] [짤 만들기]
4. **짤 만들기** (전체 화면): 뒤로, 짤 카드(캡처 영역), 이름 입력, 단어 칩 가로 스크롤, [이미지 저장 · 공유]

## 4. 근무 상태와 카운트다운
- 상태는 3가지다.

  | 상태 | 문구 | 목표 시각 |
  |---|---|---|
  | `before` | 출근까지 | 출근 시각 |
  | `working` | 퇴근까지 | 퇴근 시각 |
  | `off` | 출근까지 | 다음 출근 시각 |
- 주간 근무 (퇴근 > 출근): 자정부터 출근 전까지 before, 근무 시간은 working, 퇴근 뒤 자정까지 off.
- 야간 근무 (퇴근 ≤ 출근, 예: 22:00~06:00): 근무 시간은 working, 퇴근부터 그날 출근 전까지 off (2026-11-13 사용자). 야간 근무에는 before가 없다.
- 기본 근무 시간은 09:00~18:00. 출근·퇴근이 둘 다 있어야 저장할 수 있다.
- 카운트다운은 `HH:MM:SS`로 매초 갱신한다.
  - `setInterval`이 아니라 다음 정각 초에 맞춘 `setTimeout`을 이어 건다.
  - 매 틱마다 `Date.now()`로 다시 계산한다.
  - 화면이 가려지면(`visibilitychange`) 멈추고, 돌아오면 즉시 다시 계산한다.
  - 매초 다시 그리는 범위는 `memo`로 감싼 `<Countdown>` 안으로 한정한다.
- 카운트다운이 0이 되면 상태를 다시 계산한다.

## 5. 퇴근 보상
- 상태가 off가 되는 순간 단어 1개를 지급한다. 퇴근 후에 앱을 처음 열 때도 지급한다.
- 근무일마다 1번만 지급한다. 근무일 키는 퇴근 시각의 날짜(`YYYY-MM-DD`)이고 `bleep:lastReward`에 저장한다.
- 아직 안 모은 단어 중에서 등급 가중치로 뽑는다.

  | 등급 | 가중치 |
  |---|---|
  | common | 60 |
  | rare | 25 |
  | epic | 12 |
  | legendary | 3 |
- 다 모았으면 전체에서 뽑는다 (중복 허용, NEW 표시 없음).
- 앱을 열지 않은 날의 보상은 사라진다 (누적 없음).

## 6. 도감
- 3열 그리드로 전체 단어를 보여준다. 수집한 단어는 국기와 단어, 안 모은 단어는 ❓와 ???.
- 제목 옆에 `모은 수/전체 수`를 표시한다.
- 수집한 단어를 누르면 그 단어로 짤 만들기가 열린다.

## 7. 짤 만들기
- 문구: `아 우리 [이름]님 / [단어] 같네`
  - 이름이 비어 있으면 `XX`, 최대 10자. 긴 이름은 글자 단위로 줄바꿈한다.
  - 국가·원어와 뜻을 함께 넣는다.
- 고를 수 있는 단어는 모은 단어뿐이다.
- 캡처 영역에는 외부 이미지를 넣지 않는다 (CORS 때문에 캡처가 깨짐).
- 저장 순서:
  1. Web Share(파일)
  2. 안 되면 `<a download>`
  - 사용자가 공유를 취소하면 아무 안내도 하지 않는다.
  - 다운로드하면 "이미지를 저장했어요", 실패하면 "이미지 저장에 실패했어요. 다시 시도해 주세요."를 띄운다.

## 8. 데이터
**단어 DB** (`src/data/oaths.json`, 현재 10개)
```json
{ "id": "en-gosh", "word": "고쉬", "original": "Gosh", "country": "🇺🇸 미국",
  "meaning": "세상에 (God의 순화)", "rarity": "common" }
```

**localStorage** (모든 접근은 `try/catch`, 실패하면 메모리 상태로 동작)

| 키 | 값 | 기본값 |
|---|---|---|
| `bleep:settings` | `{ start: "HH:MM", end: "HH:MM" }` | `09:00`~`18:00` |
| `bleep:collected` | 단어 id 배열 | `[]` |
| `bleep:lastReward` | 마지막 보상 근무일 `YYYY-MM-DD` | `null` |

## 10. 완료 조건 (MVP)
- T-01~T-12가 브라우저(375px)에서 통과한다.
- 토스 앱 웹뷰 실제 기기(iOS·Android)에서 앱이 뜨고 이미지를 저장할 수 있다.

## 11. 알려진 리스크
- 토스 웹뷰에서 파일 공유(`navigator.share`)와 `<a download>`가 막혀 있을 수 있다. 막혀 있으면 앱인토스 SDK의 이미지 저장 API를 저장 순서 맨 앞에 넣는다.
- 앱인토스 입점·심사 조건(디자인, 콘텐츠 기준)을 아직 확인하지 않았다.

## 12. 정할 것
1. **주말·휴일 처리**
   - **A (추천):** 매일 근무로 본다 (지금 동작). 이유: 가장 단순하고, 쉬는 날에도 보상을 받는 게 앱 성격에 맞는다.
   - B: 근무 요일을 설정하고, 쉬는 날은 "오늘은 쉬는 날" 표시와 보상 없음.
2. **앱을 안 연 날의 보상**
   - **A (추천):** 사라진다 (지금 동작). 이유: 매일 열 이유가 생기고 구현이 단순하다.
   - B: 놓친 날만큼 다음에 한꺼번에 지급한다.
3. **단어 DB 목표 수**
   - **A (추천):** 출시 전 30개 안팎. 이유: 매일 받아도 한 달을 버티는 양이다.
   - B: 지금 10개로 출시하고 나중에 늘린다.
4. **단어 검수 기준** (예: "십장생"처럼 원래 욕을 떠올리게 하는 단어를 넣을지)
   - **A (추천):** 앱인토스 콘텐츠 기준을 확인한 뒤 정하고, 그 전까지 지금 목록 유지.
   - B: 지금 바로 원래 욕이 연상되는 단어를 뺀다.
5. **디자인 시스템**
   - **A (추천):** Tailwind를 그대로 쓴다. 심사에서 토스 디자인 시스템(TDS)을 요구하면 그때 바꾼다.
   - B: 처음부터 TDS로 옮긴다.
6. **이번 범위에서 뺄 것** (알림, 서버 동기화, 로그인, 랭킹)
   - **A (추천):** 모두 뺀다. 이유: 백엔드 없음이 전제다.
   - B: 퇴근 알림만 넣는다 (앱인토스 SDK 지원 여부를 확인해야 함).
