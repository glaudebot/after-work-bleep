# M1.5-3. 퇴근 펑 연출
> 마일스톤: M1.5 · 상위: [M1.5.md](M1.5.md)
> 상태: ✅ 완료 (2026-11-13)
## 왜 필요한가
- 퇴근 순간 화가 터지며 단어가 나오는 장면을 만든다 (D-18).
## 정해진 것
- 1~2초 펑 연출 뒤 지금 보상 창을 띄운다 (2026-11-13 사용자)
- 퇴근 뒤 처음 열었을 때도 보상과 함께 한 번 보여 준다. 보상이 없으면 연출도 없다 (2026-11-13 사용자)
- 연출: 폭발 직전 복어가 1초 떨며 부풀다가 펑 그림으로 바뀌고, 말풍선으로 뽑은 단어를 바로 보여 준다. 2.4초 뒤 보상 창 (2026-11-13 사용자 AR)
- 탭하면 건너뛰고 바로 보상 창. 기기에서 동작 줄이기를 켰으면 연출 없이 바로 보상 창 (2026-11-13 사용자 AR)
## 제약
- 보상 규칙(D-09, D-17)은 바꾸지 않는다. 연출은 `giveReward`가 보상을 준 직후에만 켜진다.
## 작은 판단
- 연출은 보상 창과 같은 전체 화면 겹침(z-50, 검은 70% 배경)으로. 어떤 화면이 열려 있어도 같은 모습.
- 펑 그림은 흰 배경을 지우고, 사각 가장자리는 CSS 원형 마스크로 흐리게.
