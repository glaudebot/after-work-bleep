# M1.5. 메인 화면 개편
> 상위: [MILESTONES.md](../../MILESTONES.md) · 이전: [M1](M1.md) · 다음: [M2](M2.md)
> 상태: 🔨 진행 중
## 목표
메인을 타이머 + 캐릭터 화면으로 바꾸고, 퇴근이 가까울수록 화가 쌓이다가 퇴근 때 펑 터지며 단어가 나오게 한다. 도감은 따로 연다. 짤 템플릿을 여러 개 두고 카드 그리드로 고른다.
## 완료 조건
- 사용자 확인: 휴대폰 미리보기에서 메인에 타이머와 캐릭터가 보이고, 시각을 바꿔 보면 단계마다 표정·배경이 바뀌며, 퇴근하면 펑 연출 뒤 보상 창이 뜬다. [도감] 버튼으로 도감이 열리고 뒤로 돌아온다.
- QA: T-01 ~ T-12, T-07a, T-16, T-17, T-18, T-19, T-20, T-21
## 정해진 것 (D-번호)
- 메인 구성, 표정 단계, 펑 연출, 도감 분리 (D-18)
- 짤 템플릿과 선택 시트 (D-19)
- 보상 규칙은 그대로 (D-09, D-10, D-17)
- 카운트다운 방식 그대로 (D-08)
