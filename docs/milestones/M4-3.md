## 진행 기록
- 2026-11-13 사용자: 토스 앱에서 짤 저장 → "이미지를 저장했어요"만 뜨고 저장 안 됨. 토스 안에서는 SDK `File.saveBase64`로 저장하도록 바꿈 (D-14 대안, M5 앞당김). 새 `.ait` 전달
- 2026-11-13 사용자: 새 `.ait`에서 짤 저장 → 공유 시트가 먼저 뜨고, 취소하니 저장됨. 앱 코드는 토스 안에서 Web Share를 부르지 않으므로(SDK 경로가 먼저 return) 공유 시트는 토스 `File.saveBase64`의 네이티브 동작으로 봄. 문서에는 UI 설명 없음 (출처: https://developers-apps-in-toss.toss.im/documentation/sdk/domains-api/file/file.savebase64.md). 코드는 그대로, 기종(iOS/Android)·사진첩 실제 저장 여부는 확인 중
- 2026-11-13 사용자 (Android): 갤러리에 이미지 저장 확인. 공유 시트에는 "이미지 저장" 항목이 없음 → 저장은 SDK가 하고, 공유 시트는 저장과 함께 뜨는 토스 기본 동작으로 확정. 코드 그대로. iOS 미확인
- 2026-11-13 사용자: 홈 배치 손봄 (디자인 피드백 일부 채택). 시계 박스 반투명 흰색 `bg-white/70`(블러는 저사양 웹뷰 부담으로 뺌), 숫자 5xl→2.75rem·박스 높이 축소, 하단 버튼 알약형·도감:짤 = 2:3, 밤에는 도감 버튼 `bg-black/40`. 박스 제거·아이콘 전용 도감·파스텔 버튼은 안 함 (밝은 배경 대비, 첫날엔 짤 버튼이 비활성, 토스 주 버튼 색). 스크린샷 다시 찍음
- 2026-11-13 사용자: 홈 도감 버튼의 "📖 도감"을 사용자 책 그림(`src/assets/book.webp`, 흰 배경 투명 처리)으로 바꿈. 글자 대신 `aria-label="도감"`. 스크린샷 다시 찍음
- 2026-11-13 사용자: 홈 짤 만들기 버튼도 카메라 그림(`src/assets/camera.webp`)으로 바꿈. `aria-label="짤 만들기"`. 파란 버튼 위 파란 카메라라 대비가 약함 → 버튼 색 확인 중
- 2026-11-13 사용자: 첫 실행 안내 추가. 한 장 안내(시계·도감·짤 말풍선) → 설정 시트 "출퇴근 시간부터 정해요" → 끝나면 `bleep:onboarded`. 대상은 안내 기록이 없고 모은 단어도 없는 폰(기존 사용자 건너뜀). 퇴근 보상은 안내가 끝난 뒤 정한 시간으로 판단. 짤 버튼 색은 사용자가 흰색 카메라 그림을 줄 예정이라 파란색 유지. QA T-25 추가
