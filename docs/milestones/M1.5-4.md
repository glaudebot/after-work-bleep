# M1.5-4. 짤 템플릿 + 선택 시트
> 마일스톤: M1.5 · 상위: [M1.5.md](M1.5.md)
> 상태: ✅ 완료 (2026-11-13)
## 왜 필요한가
- 짤 문장·디자인이 하나뿐이라 금방 질린다. 단어가 늘면(M2) 가로 칩으로는 고르기 어렵다.
## 정해진 것
- 템플릿 = 문장 + 색, 처음 6개, 처음부터 전부 열림, 짤 만들기 화면의 "▾" 줄 → 카드 2열 시트 (D-19, AR 2026-11-13 사용자)
- 문장 초안은 아래 6개. 확인받고 바꾼다.
  | id | 이름 | 문장 |
  |---|---|---|
  | basic | 노란 기본형 | 아 우리 XX님 / YY 같네 |
  | praise | 핑크 칭찬형 | XX님 오늘도 / YY 그 자체 |
  | commute | 퇴근길형 | 퇴근길에 XX님 생각나서 / 외쳤다 YY! |
  | minutes | 회의록형 | [회의록] / XX님 발언 요약: / YY |
  | breaking | 속보형 | [속보] XX님, / 오늘도 YY 판정 |
  | warning | 다크 경고형 | 경고: XX님 / YY 수치 초과 |
- 단어 시트 맨 앞에 "단어 없이" 카드. 고르면 단어 자리에 빨간 글씨 "삐-"(#ef4444, 배경 없음), 국가·원어 줄과 "뜻" 줄은 숨긴다 (2026-11-13 사용자). 모은 단어가 하나도 없으면 짤 만들기는 지금처럼 막혀 있다.
- 고른 템플릿은 저장하지 않는다. 짤 만들기를 열 때마다 기본형.
