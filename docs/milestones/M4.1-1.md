# M4.1-1. 광고 SDK 조사와 콘솔 준비
> 마일스톤: M4.1 · 상위: [M4.1.md](M4.1.md)
> 상태: 🔨 진행 중 (광고 그룹 ID 대기)
## 왜 필요한가
- 전면 광고를 띄우려면 콘솔에서 받은 광고 그룹 ID(`adGroupId`)가 있어야 하고, SDK 사용 순서와 정책을 지켜야 한다.
## 정해진 것
- 전면형만, 짤 저장 뒤, 하루 1번(`bleep:lastAd`), 공유 취소 땐 안 띄움 (D-16)
- 콘솔 작업(사업자 정보, 정산 정보, 광고 그룹 생성)은 사용자 (콘솔 계정이 필요해서)
## 조사한 것 (2026-11-14)
- 출처: https://developers-apps-in-toss.toss.im/documentation/common/monetization/iaa/interstitial-rewarded-ad.md
  - 전면형과 보상형 모두 `loadFullScreenAd` → `showFullScreenAd`를 쓴다. 광고 종류는 `adGroupId`로 정해진다
  - 반드시 load → 'loaded' 이벤트 → show 순서. 같은 `adGroupId`는 한 번에 하나만 미리 불러온다
  - show 이벤트: `show`, `dismissed`(닫음), `failedToShow` 등
  - `loadFullScreenAd.isSupported()`로 지원 여부를 확인한다. 토스 5.227.0 미만은 지원하지 않는다
  - iOS는 앱 추적 허용(ATT)이 꺼져 있으면 광고가 안 불러와질 수 있다
- 출처: https://developers-apps-in-toss.toss.im/guide/monetization/in-app-ad.md
  - 콘솔 순서: 사업자 정보 → 정산 정보 → 광고 그룹 생성 → 상세 화면에서 ID 확인
  - 새 ID는 구글 등록까지 최대 2시간 걸린다
  - 광고 영역을 주기적으로 새로 고치는 등의 비정상 트래픽은 위반이다
- 설치된 SDK(`@apps-in-toss/web-framework`) `index.d.ts`에 `LoadFullScreenAdOptions`와 `ShowFullScreenAdEvent` 타입이 있다
- 광고 그룹 ID는 코드 상수 `src/lib/ads.js`의 `AD_GROUP_ID` (2026-11-14 사용자, AR). 비어 있으면 광고를 부르지 않는다
- 테스트용 ID: 문서 예시에는 보상형 테스트 ID(`ait-ad-test-rewarded-id`)만 있다. 전면형은 콘솔에서 만든 ID로 테스트 환경에서 확인한다
- SDK 타입(`index.d.ts`, 2026-11-14): load 옵션 `{ adGroupId }`, load 이벤트는 `loaded`, show 이벤트는 `clicked`·`dismissed`·`failedToShow`·`impression` 등
