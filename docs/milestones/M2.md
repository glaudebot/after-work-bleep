# M2. 단어 확장
> 상위: [MILESTONES.md](../../MILESTONES.md) · 이전: [M1](M1.md) · 다음: [M3](M3.md)
> 상태: ⏳ 예정
## 목표
단어를 10개에서 100개 이상으로 늘린다. 수위 기준과 등급 비율을 맞춘다.
## 완료 조건
- 사용자 확인: 도감 전체 수가 100개 이상이고, 여러 번 퇴근(시각 조작)해 보면 등급별로 다른 단어가 나온다.
- QA: T-01 ~ T-12, M2에서 추가할 단어 데이터 검사 항목
## 정해진 것 (D-번호)
- 정적 JSON을 코드에 포함, 많을수록 좋음, 형식 유지 (D-11)
- 순화 비속어·장난스러운 욕·순한 욕만 (D-12)
## 정할 것
- 목표 단어 수 (추천: 100개)
- 등급별 개수 비율
- '십장생'처럼 경계선에 있는 단어 처리

| 꼭지점 | 내용 |
