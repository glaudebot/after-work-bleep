> 마일스톤: M1 · 상위: [M1.md](M1.md)

## 왜 필요한가
- iPhone처럼 홈 인디케이터가 있는 기기에서 설정 시트의 저장 버튼이 화면 아래 끝에 붙는다. `index.html`에 `viewport-fit=cover`가 있어서 safe-area 여백을 직접 줘야 한다.
- 출근 = 퇴근으로 저장하면 `getWorkPhase`가 야간 근무 분기(`e <= s`)로 들어가 항상 working이 된다. off가 오지 않아 보상을 영영 못 받는다.
## 정해진 것
- 기본 근무 시간 09:00~18:00, 둘 다 있어야 저장 (spec.md 4장)
- 야간 근무 규칙 (D-07, 2026-11-13)
## 제약
- `getWorkPhase` 상태 규칙(D-07)은 바꾸지 않는다.
## 정할 것
1. **출근 = 퇴근 처리**
   - **A (추천):** 설정 시트에서 저장 버튼을 비활성하고 "출근과 퇴근 시각이 같아요" 안내. 이유: 의미 없는 입력이고, 시간 계산을 건드리지 않는다.
   - B: 24시간 근무로 보고 `getWorkPhase`에서 처리. 시간 로직과 테스트가 늘어난다.
