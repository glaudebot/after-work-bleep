# M5-1. 실제 기기에서 지금 저장 방식 확인
> 마일스톤: M5 · 상위: [M5.md](M5.md)
> 상태: ✅ 2026-11-14
## 왜 필요한가
- M5 완료 조건: 실제 휴대폰에서 짤을 사진첩에 저장하거나 공유할 수 있다 (T-15).
## 정해진 것
- 토스 안에서는 SDK `File.saveBase64`로 저장한다 (D-14 대안, M4-3에서 앞당김)
- iOS 실제 기기 확인은 출시 뒤 실제 사용자 테스트로 대체한다 (2026-11-14 사용자, M4 마감)
## 확인한 것
- 2026-11-13 사용자 (Android): 갤러리 저장 확인. 저장과 함께 토스 공유 시트가 뜨는 것은 토스 기본 동작 (M4-3 진행 기록)
- 2026-11-14 문서: `File.saveBase64`는 토스 Android 5.218.0, iOS 5.216.0 이상에서 쓸 수 있다. 권한 안내는 문서에 없다
  (출처: https://developers-apps-in-toss.toss.im/documentation/sdk/domains-api/file/file.savebase64.md)
- 그보다 낮은 버전은 `isSupported()`가 false라서 Web Share → 다운로드로 넘어간다. 토스 웹뷰에서는 이 경로가 조용히 무시된다 (M4-3)
