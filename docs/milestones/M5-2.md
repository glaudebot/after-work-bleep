# M5-2. 막힌 경우 SDK 저장 API 연결
> 마일스톤: M5 · 상위: [M5.md](M5.md)
> 상태: ✅ 2026-11-14 (M4-3에서 앞당겨 함)
## 왜 필요한가
- 토스 웹뷰에서 Web Share와 `<a download>`가 조용히 무시되어 "저장했어요"만 뜨고 저장되지 않았다 (2026-11-13 사용자, M4-3).
## 정해진 것
- 토스 안에서 `File.saveBase64`가 지원되면 그것을 맨 앞에 둔다 (D-14 대안, 2026-11-13 사용자)
## 지금 구조 (2026-11-14)
- `src/lib/captureAndSave.js` `captureAndShare`: 토스 + `saveBase64.isSupported()`이면 base64로 저장하고 `'saved'`를 돌려준다. 아니면 Web Share → 다운로드
- `MemeMaker.jsx`: `'saved'`이면 "사진첩에 저장했어요"
