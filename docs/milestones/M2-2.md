# M2-2. 반영 후 도감·보상 화면 확인
> 마일스톤: M2 · 상위: [M2.md](M2.md)

## 왜 필요한가
- 단어가 100개가 되면 도감 목록 길이, 긴 단어(예: 징스 크리븐스 헬프 마 보브)의 줄바꿈이 보상 창·펑 말풍선·짤에서 깨지지 않는지 봐야 한다.
## 정해진 것
- 긴 단어는 글자 크기를 줄이지 않고 줄바꿈 허용 (2026-11-13 사용자 AR)
  - 보상 창·짤은 이미 줄바꿈되어 그대로 둔다
  - 펑 말풍선 글자 가운데 정렬
  - 도감 칸은 말줄임(truncate) 대신 단어 단위 줄바꿈(`break-keep`), 띄어쓰기 없는 긴 단어는 칸 안에서 끊음(`overflow-wrap:anywhere`). 줄 수 제한 없음
- 도감 필터는 이번에 넣지 않음 (2026-11-13 사용자 AR). 국가·등급 분류는 [M3](M3.md)에서 한다
