# M1.5-2. 캐릭터와 표정 단계
> 마일스톤: M1.5 · 상위: [M1.5.md](M1.5.md)
> 상태: ✅ 완료 (2026-11-13)
## 왜 필요한가
- 퇴근이 다가올수록 화가 쌓이는 모습을 보여 준다 (D-18).
## 정해진 것
- 캐릭터 그림은 사용자가 준다 (2026-11-13 사용자). 넣을 곳: `src/assets/character/`
- 표정 단계: 출근 전 졸림 / 근무 0~50% 무표정 / 50~80% 짜증 / 80~95% 화남 / 95%~퇴근 폭발 직전(떨림) / 퇴근 후 후련. 구간 값은 임시 (D-18)
- 배경: 기기 시각으로 아침 06~11시, 점심 11~18시, 밤 18~06시. 사용자 그림, 오기 전까지 그라데이션 (2026-11-13 사용자)
- 받을 그림: 캐릭터 `sleepy` `calm` `annoyed` `angry` `furious` `relieved`(+선택 `boom`) PNG 투명 512×512 이상, 배경 `morning` `noon` `night` 세로 1080×1920 정도
- 캐릭터: 분노의 복어. 출근 땐 홀쭉·평온, 퇴근이 다가올수록 부풀고 가시가 돋음, 정시에 펑 터지며 비속어 카드를 뱉음 (2026-11-13 사용자)
- 배경: 사무실 책상 위 어항, 창밖이 아침·점심·밤으로 바뀜. 어항 안은 비워 두고 복어 PNG를 위에 겹친다 (2026-11-13 사용자)
## 제약
- 매초 다시 그리는 범위는 `<Countdown>`으로 둔다 (D-08). 표정은 단계가 바뀔 때만 다시 그린다.
- 메인 화면은 캡처 영역이 아니라 이미지 파일을 써도 된다 (D-14는 짤 카드에만 해당).
## 정할 것
- 없음 (AR, 2026-11-13 사용자). 정한 것:
  - 받은 그림 1~4·6은 흰 배경을 지우고(가장자리에서 흰색만 채워 지움) 768px WebP로. 그림마다 자르지 않고 전체 크기만 맞춰 단계별로 부푸는 차이(몸 높이 57→61→67→72%)를 살린다.
  - 5번(폭발 장면)은 `boom`으로 M1.5-3에서 쓴다. `furious`는 사용자가 따로 준 그림(2026-11-13)에 떨림·1.1배·붉은 빛을 더한다. 그림 크기가 `angry`와 비슷해서 1.1배로 더 부푼 느낌을 낸다.
  - 표정·배경은 30초마다와 화면 복귀 때 다시 계산. 매초 다시 그리는 범위는 그대로 `Countdown` (D-08).
  - 밤 배경에서는 머리글 글자를 흰색으로.
  - 떨림은 `prefers-reduced-motion`이면 끈다.
