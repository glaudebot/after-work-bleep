# M4-2. SDK 설치와 빌드 설정
> 마일스톤: M4 · 상위: [M4.md](M4.md)
> 상태: ⏳ 예정
## 왜 필요한가
- 토스 앱에 올릴 번들을 만들려면 SDK와 앱인토스 빌드 설정이 있어야 한다.
## 알고 시작할 것 (M4-1)
- `@apps-in-toss/web-framework` 3.10.0, `npx ait init`, `apps-in-toss.config.ts` (`appName`, `webBundleDir: 'dist'`), `build` = `vite build && ait build`
- 체크리스트: 핀치 줌 막기, 토스 뒤로가기와 자체 ← 뒤로 중복 금지, 안드로이드 백버튼·첫 화면 뒤로가기는 종료
## 정할 것
- `appName` (콘솔에 등록한 값, 사용자)
- 뒤로가기: 토스 바 뒤로가기만 쓰고 자체 ← 뒤로를 없앨지, 자체 버튼을 두고 바 뒤로가기를 끌지 (설치된 SDK 이벤트 확인 후)
