## 왜 필요한가
- 토스 앱에 올릴 번들을 만들려면 SDK와 앱인토스 빌드 설정이 있어야 한다.
## 알고 시작할 것 (M4-1)
- `@apps-in-toss/web-framework` 3.10.0, `npx ait init`, `apps-in-toss.config.ts` (`appName`, `webBundleDir: 'dist'`), `build` = `vite build && ait build`
- 체크리스트: 핀치 줌 막기, 토스 뒤로가기와 자체 ← 뒤로 중복 금지, 안드로이드 백버튼·첫 화면 뒤로가기는 종료
## 정해진 것
- `appName`: `afterworkbleep` (2026-11-13 사용자)
- 뒤로가기는 토스 바 것만 쓴다. 토스 안에서는 자체 `← 뒤로`를 숨긴다 (2026-11-13 사용자)
  - 구현: 열린 화면(시트·보상 창·도감·짤)이 `useTossBack`으로 스택에 올라가고, `graniteEvent` `backEvent`가 오면 맨 위 화면만 닫는다. 스택이 비면(메인) 구독을 풀어 토스 기본 동작(미니앱 종료)에 맡긴다
  - 토스 판별: SDK가 `window.ReactNativeWebView` 없으면 throw하므로 그 값으로 판별 (설치된 SDK `dist/index.js` `assertWebViewEnvironment`). 브라우저에서는 SDK를 안 부르고 자체 `← 뒤로`를 그대로 보인다
