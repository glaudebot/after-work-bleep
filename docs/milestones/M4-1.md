## 알아낸 것
- **설치:** `npm install @apps-in-toss/web-framework` → `npx ait init` → `apps-in-toss.config.ts` 생성. `appName`은 콘솔에 등록한 값과 같아야 업로드된다. 출처: https://developers-apps-in-toss.toss.im/ai-vibe-coding/tutorials/webview.md
- **버전:** npm 최신 3.10.0 (2026-11-06). React peer 의존성 없음 → React 19 그대로. 3.0.x는 localStorage origin이 달라지므로 3.1.0 이상만 쓴다. 출처: https://developers-apps-in-toss.toss.im/documentation/integration/sdk-3.x.md
- **빌드:** `package.json` `build`를 `vite build && ait build`로, 설정 `webBundleDir: 'dist'`. 결과물 `.ait`를 콘솔에 올리면 테스트 QR(`intoss-private://...?_deploymentId=`)이 나온다. 출처: 위 sdk-3.x, https://developers-apps-in-toss.toss.im/guide/operation/toss.md
- **테스트:** 3.x는 샌드박스 앱 없이 `npm run dev` 로컬 devtools, 최종은 토스 앱 QR. 토스 앱 안 로그는 내비게이션 바 더보기 → 웹 디버그 툴즈. 출처: https://developers-apps-in-toss.toss.im/development/test/sandbox.md, guide/operation/toss.md
- **설정 `webView`:** bounces·overScrollMode 등. 핀치 줌은 viewport meta `maximum-scale=1, user-scalable=no`로 막는다 (지금 index.html엔 없음). 출처: https://developers-apps-in-toss.toss.im/documentation/integration/props.md
- **내비게이션 바:** 비게임은 흰 바(로고·이름·더보기·X)가 자동. `navigationBar.withBackButton` 등으로 설정. 출처: https://developers-apps-in-toss.toss.im/documentation/common/navigationbar.md
- **비게임 체크리스트에서 이 앱에 걸리는 것** (출처: https://developers-apps-in-toss.toss.im/checklist/app-nongame.md)
  - "미니앱 문구에 비속어, 은어, 과도한 유행어가 포함되지 않아요" → 앱 핵심(순화 비속어)과 부딪칠 수 있다. D-13, TODO.md
  - 토스 뒤로가기와 자체 뒤로가기(도감·짤의 ← 뒤로)가 동시에 보이면 안 되고, 첫 화면에서 뒤로가기·안드로이드 백버튼은 미니앱 종료 → M4-2
  - 핀치 줌 막기, 라이트 모드(지금 dark: 클래스 없음 ✓), iframe 금지(안 씀 ✓), SSR 금지(Vite CSR ✓)
  - 광고는 예상할 수 있을 때만, 사전 로딩 → M4.1 (D-16과 맞음)
