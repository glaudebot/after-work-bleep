# M6. 앱 테스트와 출시
> 상위: [MILESTONES.md](../../MILESTONES.md) · 이전: [M5](M5.md) · 다음: 없음
> 상태: 🔨 진행 중 (심사 중)
## 목표
앱인토스 앱 테스트를 통과시키고 출시한다.
## 완료 조건
- 사용자 확인: 심사를 통과하고, 토스 앱에서 누구나 미니앱을 열 수 있다.
- QA: 전체
## 정해진 것 (D-번호)
- 디자인은 Tailwind, 요구하면 TDS (D-05)
- 세부 검수 기준은 앱인토스 기준 확인 후 (D-13)
- 앱 테스트 통과 뒤 출시 요청을 하면 심사를 거친다. 처음 계획(심사 대기 없음)과 다름 (2026-11-14 사용자)
- 심사에 올린 빌드는 `AD_GROUP_ID`가 비어 있어 광고가 나오지 않는다. 광고는 ID를 받은 뒤 업데이트로 넣는다 (M4.1)
