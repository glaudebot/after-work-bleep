# M6. 앱 테스트와 출시
> 상위: [MILESTONES.md](../../MILESTONES.md) · 이전: [M5](M5.md) · 다음: 없음
> 상태: 🔨 진행 중 (심사 중)
## 목표
앱인토스 앱 테스트를 통과시키고 출시한다.
## 완료 조건
- 사용자 확인: 심사를 통과하고, 토스 앱에서 누구나 미니앱을 열 수 있다.
- QA: 전체
## 정해진 것 (D-번호)
- 디자인은 Tailwind, 요구하면 TDS (D-05)
- 세부 검수 기준은 앱인토스 기준 확인 후 (D-13)
- 앱 테스트 통과 뒤 출시 요청을 하면 심사를 거친다. 처음 계획(심사 대기 없음)과 다름 (2026-11-14 사용자)
- 심사에 올린 빌드는 `AD_GROUP_ID`가 비어 있어 광고가 나오지 않는다. 광고는 ID를 받은 뒤 업데이트로 넣는다 (M4.1)
- 앱 카테고리를 교육으로 변경. 콘솔 설정이라 코드 변경 없음 (2026-11-15 사용자)
- 심사 반려 1 (2026-11-15): 첫 화면에서 토스 바 뒤로가기로 미니앱이 안 닫힘 → `src/lib/toss.js`에서 첫 화면 뒤로가기 때 `Screen.close()`로 수정. 실기기 확인 뒤 재제출
- 심사 반려 2 (2026-11-15): 같은 이유. 원인은 처음 연 폰의 첫 화면이 사용 안내(Tour)이고, 안내가 뒤로가기를 받아 "다음"으로 넘겼기 때문. 심사자는 새 폰으로 열어서 안내 화면에서 뒤로가기를 누름. Tour에서 `useTossBack` 제거 → 첫 화면이면 `Screen.close()`. 가짜 토스 브리지로 재현·확인(이전 코드 종료 안 됨, 고친 코드 종료), QA T-31로 자동화
- 2026-11-15 사용자: 짤 템플릿에서 이름 뒤 "님" 제거, 템플릿 6개 추가(메신저·날씨예보·운세·일기장·상장·메뉴판, 총 12개). 이름 받침에 따라 조사가 틀리지 않게 {XX} 바로 뒤에 조사를 안 붙임. 다크 경고형은 QA T-18 때문에 마지막 유지
