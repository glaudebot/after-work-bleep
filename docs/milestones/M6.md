## 목표
앱인토스 앱 테스트를 통과시키고 출시한다.
## 완료 조건
- 사용자 확인: 심사를 통과하고, 토스 앱에서 누구나 미니앱을 열 수 있다.
- QA: 전체
## 정해진 것 (D-번호)
- 디자인은 Tailwind, 요구하면 TDS (D-05)
- 세부 검수 기준은 앱인토스 기준 확인 후 (D-13)
- 앱 테스트 통과 뒤 출시 요청을 하면 심사를 거친다. 처음 계획(심사 대기 없음)과 다름 (2026-11-14 사용자)
- 심사에 올린 빌드는 `AD_GROUP_ID`가 비어 있어 광고가 나오지 않는다. 광고는 ID를 받은 뒤 업데이트로 넣는다 (M4.1)
- 앱 카테고리를 교육으로 변경. 콘솔 설정이라 코드 변경 없음 (2026-11-15 사용자)
- 심사 반려 1 (2026-11-15): 첫 화면에서 토스 바 뒤로가기로 미니앱이 안 닫힘 → `src/lib/toss.js`에서 첫 화면 뒤로가기 때 `Screen.close()`로 수정. 실기기 확인 뒤 재제출
- 심사 반려 2 (2026-11-15): 같은 이유. 원인은 처음 연 폰의 첫 화면이 사용 안내(Tour)이고, 안내가 뒤로가기를 받아 "다음"으로 넘겼기 때문. 심사자는 새 폰으로 열어서 안내 화면에서 뒤로가기를 누름. Tour에서 `useTossBack` 제거 → 첫 화면이면 `Screen.close()`. 가짜 토스 브리지로 재현·확인(이전 코드 종료 안 됨, 고친 코드 종료), QA T-31로 자동화
- 첫 단어 선물 (2026-11-23 사용자): 근무 중에 처음 열면 시간 설정뿐이라 할 게 없음 → 첫 실행 안내를 끝낸 순간 근무 시간이면 한 번 뽑아 줌. 평생 한 번(안내는 처음 연 폰에만 뜸)("첫 단어 선물이에요"). 퇴근 보상(`lastReward`)은 쓰지 않아 그날 퇴근하면 또 받음. 퇴근 후에 처음 열면 원래 퇴근 보상만. QA 기본 도감은 1개로 바꿈, T-32 추가
- 템플릿 교체 (2026-11-24 사용자): 기존 12개를 지우고 단어 분류별 16개(감탄사 4, 명사 외침 4, 사람 4, 공용 4)로. 단어마다 `type`(interjection 77 / noun 22 / person 3, 뜻의 품사 기준. 서술어 2개와 십장생은 감탄사로). 짤 만들기는 고른 단어 분류와 공용 템플릿만 보여 주고, 단어 없이(삐-)는 전부. 받은 문구 중 어색한 것은 고침(명사형 수식어, 동화형 → 한마디형, 겹치는 이름, "{YY} !!" 띄어쓰기). 색은 전부 밝은 배경 한 벌. QA T-09·T-18 수정
- 출시 (2026-11-23, 사용자). 첫 단어 선물·템플릿 교체·직접 쓰기는 출시 번들 뒤의 변경이라 업데이트로 올린다
- 직접 쓰기 (2026-11-24 사용자 AR): 템플릿 시트 맨 앞 "직접 쓰기". 문장 3줄·한 줄 15자, 고른 단어는 마지막 줄 끝에 붙음, 배경색 6개, 이름 칸은 숨김(문장에 직접 씀). 최근 1개만 `bleep:custom`에 저장. `{}`는 지움. 띄어쓰기 없는 긴 줄이 카드 밖으로 넘쳐 짤 문장에 `overflow-wrap:anywhere` 추가(모든 템플릿 공통). QA T-33
