# M3-1. 분류 화면 구성 확정
> 마일스톤: M3 · 상위: [M3.md](M3.md)

## 왜 필요한가
- 단어가 102개, 국가 21개라 한 그리드로는 어느 나라·등급을 얼마나 모았는지 안 보인다 (spec.md 6장).
## 정해진 것
- 안 모은 칸: 국기 자리에 빨간 `삐-`(국기 이모지와 같은 크기, text-xs), ??? 줄은 뺌. 이미지 아닌 글자 (2026-11-13 사용자). 반영: `src/components/Collection.jsx`, spec.md 6장
- 분류 방식: 묶어 보기. 제목 아래 칩 `[전체] [국가별] [등급별]`, 국가별·등급별이면 소제목 + 모은 수로 나눠 3열 그리드 (2026-11-13 사용자 AR)
  - 국가는 단어 많은 나라부터, 등급은 전설 → 일반, 소제목은 등급 색
  - 화면 열 때마다 "전체", 고른 칩은 저장하지 않음
- 국가별은 소제목 묶음 대신 나라 카드 그리드(국기·이름·모은 수, 단어 많은 나라부터). 카드를 누르면 그 나라 단어만 보이고, ← 뒤로는 나라 카드로 돌아간다 (2026-11-13 사용자). 등급별은 소제목 묶음 그대로
- 안 모은 단어도 묶음 안에 빨간 삐- 칸으로 둔다 (2026-11-13 사용자 AR)
- M3 완료 조건 문구: "국가별·등급별로 묶어 볼 수 있다" (2026-11-13 사용자 AR)
