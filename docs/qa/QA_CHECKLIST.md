# QA 체크리스트

> 출처: spec.md 9장(테스트 시나리오), 10장(완료 조건). 마일스톤 마감 때 전체를 돌리고 결과를 마일스톤 문서 "마감" 절에 적는다.
> `npm run qa`가 T-01~T-12, T-07a, T-17, T-18, T-19, T-20, T-21, T-23, T-24, T-25, T-26, T-28, T-29를 자동으로 돌린다. T-16, T-22는 `npm test`가 검사한다. T-10은 `qa-out/` 두 이미지를 눈으로도 비교한다.
> 브라우저 항목은 375px 세로 화면 기준. 시각은 기기 시계나 테스트용 시각 조작으로 맞춘다.
